# Practive

Ce depot contient les projets et devoirs realises dans le cadre du stage de programmation en C# (OmGTU, groupe MO-251).

## Structure du projet

Tous les projets sont organises dans le dossier `practice2026/` :

- `task01` a `task15` : implementations des differentes taches du stage
- `taskXXtests` : projets de tests associes (xUnit/NUnit)
- `CommandLib`, `CommandRunner`, `FileSystemCommands`, `PluginA`, `PluginB` : bibliotheques liees au systeme de plugins (task08/task10)

## Compilation

```powershell
dotnet build
```

## Tests

```powershell
dotnet test
```
